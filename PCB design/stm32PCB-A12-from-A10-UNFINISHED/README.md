# A12：A10 基线副本，未完成，不可制板或上电

本目录的 `stm32PCB` 是 A10 原生工程的原样副本，并非完成的 A12；没有修改原理图、PCB、网络或丝印。现有 `stm32PCB-A12` 是另一套未完成的草稿，未覆盖。

## 本次目标

- TB6612 模块 J8.1 VM 接电池正极，电机支持 12 V；其逻辑 VCC 仍为核心板提供的 +3V3，共地。
- 原 12 V 输入降压为约 5 V、通过核心板产生 3.3 V 的供电保持。新增三组顶面右侧两针排针，各为 +3V3/GND 并联，标清极性。

## 必须完成的工程修改

1. A10 的 VM 同时是降压输出、反馈分压及 R4 到核心板 +5V 的节点；将其保留为 5 V 网络，另建电机供电网，仅把 J8.1 和其去耦 C1/C2 的电源端从原网分出。核实 J2 原功能及其他原 VM 引脚，避免误接 12 V。
2. 用户指定电池正极直连：确定 J13.1 原始电池正极到 J8.1 的走线和保护范围；直接接在 F1、D1 之前会绕过原保险和防反接保护，须在原理图和接口标注中明确，不能悄悄改成经过它们。核验线宽、铜层、电流、接插件及回流路径。
3. 重新核验 C1/C2 与模块自带电容在最大电压、尖峰及直流偏压下的耐压、有效容量和位置；评估电机回灌以及欠载和接断电瞬态。
4. 新增三个 2 针器件并在 PCB 右侧顶面布局、布线、标注，检查与核心板、外壳及插头的间隙；+3V3 由核心板稳压器供给，需按外设总电流与压差核算其容量与温升。
5. 同步原理图和 PCB，验证网表、隔离和铜连通性；重铺铜并执行严格 DRC、机械检查，重新导出并核对生产文件。A10 原有 DRC 和 Gerber 不适用于本副本的修改结果。

## 供电边界

用户已确认电机支持 12 V。TB6612FNG 的 VM 工作范围上限为 13.5 V；12 V 标称电池须核实满充电压及运行尖峰，不能仅按标称电压判断。原有项目记录单电机堵转电流不超过 2 A，需按实际电机与驱动器持续、堵转和温升能力重新评估，不能将峰值电流视为持续工作能力。
