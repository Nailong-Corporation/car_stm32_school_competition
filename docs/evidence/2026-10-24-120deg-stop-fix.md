# 2026-10-24 首项右转 120° 后低速停车

## 板上证据

用户授权通过已连接 ST-Link 自行读取。以 1000 kHz 连接，电压约 3.244 V；短暂停核后读取 SRAM 0x20000000 起 2048 B 和 Flash 0x08000000 起 32768 B，随后 resume 并断开调试连接。未复位、未烧录、未请求启动。原始文件为同目录 `2026-10-24-120deg-stop-ram.bin` / `2026-10-24-120deg-stop-flash.bin`，离线按读取前 ELF 类型解析为 `2026-10-24-120deg-stop-decoded.txt`。Flash 起始全部本地 firmware.bin 的 24560 B 逐字节匹配。

- 第 0 项：55±5 cm，CUSTOM_TURN +120°，60 cm/s；表共六项。
- 原因 LINE_STOP_ROUTE / ROUTE_FAILURE_ACTION_TIMEOUT；停车前 LINE_JUNCTION / ROUTE_EXECUTING。
- 动作年龄 6000 ms，符合 4500×120/90 的自定义动作时限；采样时刻 19770 ms。
- 转角 2.07972598 rad（约 119.16°）；目标 2.094395 rad。
- 单一区域窄线 0x04，position=-3；出口候选 pending=1，持续 3740 ms、前进 20.3509216 cm，中心确认 0 帧。
- 左右目标 6.8/5.2 cm/s，实测 5.565979/5.54048347 cm/s，速度故障 NONE。

确定触发是动作超时；快照不包含此前完整传感器与轮速序列，不能据此还原所有运动过程或认定实际轮速一直如此。

## 软件机制与修正

捕获位置 PID 请求向左回线，但原最小同向半差在转角小于精确 120° 时始终覆盖反向修正，仍输出右转半差 0.8 cm/s。快照对应的等速轮速和偏侧窄线输入可在主机复现持续不允许回线。

现在仅在原有界出口证据已经充分时解除同向下限：本帧路径更新认定角度在目标前最多 min(0.05 rad,目标10%) 范围、单一窄线连续至少 50 ms 且前进至少 0.25 cm。此时允许位置 PID 和航向项合成反向差速回线，左右轮目标仍为非负。证据不足/无线/歧义/角度退回下限以下会恢复最小同向半差；受限多区域附带分支不使用该放行。最终离口仍需原来的连续 3 帧中心线，动作时限、离口时限、最大/反向角度和反馈故障保护均保留。没有修改路径表、转角目标、速度参数或丢线开关。

## 验证

新增 +120°/-120° 镜像控制器回归，修改前在“证据充分后应允许反向回线”断言失败；修改后通过。覆盖证据积累前仍维持同向下限、偏侧线不会直接退出、证据中断后重新启用下限、重新积累后中心连续确认、离口后推进下一项并恢复加速。该测试使用合成传感器/计数输入，不代表实际车辆能达到目标轮差。

`sh test/run_host_tests.sh` 全套通过，导航两种极性各 344176 checks；覆盖三个模式及丢线开关两种设置。`pio run` 成功，RAM 1140 B，Flash 24372 B。`git diff --check` 通过。

新固件尚未烧录，实车出口收敛效果待复测。
