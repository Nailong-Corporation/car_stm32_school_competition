# 2026-10-24 IMG_1011 地板练习细缝过滤

用户确认练习地板瓷砖缝有干扰，正式比赛没有。图片可见黑胶带旁的细深色缝；图片不能确定每种材料在各通道上的实际数字电平或覆盖宽度，本次未读取新的板上快照。

## 修改

- `FLOOR_SEAM_FILTER_ENABLED=1` 为当前地板练习配置。先按颜色转换逻辑并执行原三帧逐路多数滤波，再删除无相邻目标位的独立单路区域。开关为 0 时恢复原空间响应，正式比赛须改为 0 后重新构建和上传。
- 示例：0x98 -> 0x18、0x99 -> 0x18；0x03/0xc0 保持，0xff 仍歧义，多块两路区域仍多区域。纯单路 0x80 -> 0，不能启动或更新位置 PID，按既有无可靠线保持/停车逻辑处理。
- 避免过滤后的空掩码误触发预设路径骤变：`seam_mask != 0 && line_mask == 0` 不进入强制转向分支。原本全零输入的原入口行为保持；真实连续宽分支仍可触发。
- 原始 GPIO `raw_mask` 保留；新增 `prefilter_mask`（多数滤波后、空间剔除前）、`seam_mask`（本帧剔除位）。实时 g_diagnostics 和停车前 observation 均可查看。
- 现有模式、路径、距离/转角/速度、丢线开关及故障保护不修改。不增加 PlatformIO 环境。

## 限制

这是利用宽度差异的可关闭练习规则。胶带也须能覆盖连续至少两路；胶带在边缘仅剩一路时同样会被抑制，不能声称可靠识别瓷砖。连续两路细缝、与胶带连通的缝、横向整排缝仍可能干扰。若真胶带经常只有一路，需要关闭此模式或先核对传感器高度、阈值和真实线宽，不能以软件假定代替材料验证。
