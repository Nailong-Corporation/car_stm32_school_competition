源码可复现的入口空档：首项为启用圆弧的 +90° CUSTOM_TURN，下一项 STRAIGHT 距离仅 20 cm；前置灰度会在前项仍 EXECUTING/CLEARING 时扫到电阻入口。此前约 77° 中心线或满 1 s 单线退出可提前把控制交给普通位置 PID；即使 STRAIGHT 内部已屏蔽侧线，前项离口的单侧线仍能产生很大反向轮差。

同一合成右转末端几何（目标航向尚差 +0.02 rad、左侧单线 0x01）对修改前后源码回放：旧版左/右目标 18.200001/43.399998 cm/s、position_pid_active=1；新版 31.039999/30.559999 cm/s、position_pid_active=0。见 probe-before.txt/probe-after.txt。该回放证明软件机制存在，不等于实际入口瞬间采到相同轮速。

本次仅对“90° 圆弧后紧接显式 STRAIGHT”增加出口保护：圆弧末段不按图形位置捕获，不走中心线/1 s 单线提前退出；目标出口航向 ±0.05 rad（约 ±2.9°）连续 3 个相邻合法采样后进入 CLEARING，灰度不参与该确认。原动作超时、反向/过转保护优先，超时在线不绕过本类对齐。离口全程保持出口轴、冻结位置 PID，按下一 STRAIGHT 目标渐升；3 cm 常规离口，下一窗口临近时已对齐后至少 0.5 cm 可交接，无需中心线。其他转弯及 STOP 规则保留，当前 STRAIGHT 表速和出口后 20 cm 禁止提前左转的规则保留。

新增两份入口证据：g_diagnostics.straight_entry_aligned / straight_entry_handoff，分别锁存首次对齐进入 CLEARING、首次切到 STRAIGHT 时的观测/阶段/索引/时间、实际与目标航向、出口位移、左右目标及 PID 状态。后续停车/自动恢复不覆盖，人工 START 清空。RAM 记录复位/断电丢失。
