# STRAIGHT 通过矩形电阻图形的侧线干扰

2026-10-25，用户提供 IMG_1023.HEIC，要求路径表 STRAIGHT 通过电阻图形时不受两侧线影响。图片中矩形内部没有中心胶带线，不能假定有中心线可供连续跟随。

ST-Link 只读连接，GDB 短暂停核后 detach 恢复，未复位、未烧录、未写运行变量。读取前 ELF 保存在 `/tmp/car-resistor-before/firmware.elf`；导出的 27336 B Flash 映像与板上从 0x08000000 起对应全部字节一致，差异 0，SHA-256 `5704fee0befb33e12dbf440f9a03344ca9a0e42125cbcf86bcdb7b8d3e854fdb`。完整 Flash、修改前 ELF 在该临时目录，可能被系统清理。原始诊断见 [gdb.txt](gdb.txt)。读取时处于按键停车，输出为零。

- 当前 stop_snapshot：LINE_STOP_REQUEST，索引 2，ROUTE_EXECUTING，LINE_JUNCTION，观测全目标 0xff；直行动作年龄 1510 ms，左右目标 29.547554/30.452446 cm/s。当前停车为按键停车，不能当作故障停车。
- auto_resume_count=3。保留的 auto_resume_snapshot：索引 2，FOLLOW 越窗，route_progress=59.1429596 cm，观测 0x01、单区域、position=-7；左右目标 0.400000572/25.5999985 cm/s，反馈 20.3115158/20.3176384 cm/s。证明提交直行动作前，最左侧单点确实曾进入位置控制并产生很大轮差；没有完整传感器历史，无法唯一确定该单点对应图片的哪个位置或越窗的全部物理原因。

修正仅限路径 STRAIGHT：距离窗口内由相邻稳定窄线（上一帧居中）遇骤变或移到非中心侧线时，立即进入原直行动作，冻结位置 PID 并保持入口航向。单侧单点也受到入口保护。保持原直行 4500 ms 动作时限、至少 3 cm + 连续 3 帧居中单线退出；CLEARING 继续保持入口航向，侧线不参与位置 PID，也不能作为离口完成证据，仍受独立 1500 ms 时限约束。路径表、圈数、轮速与丢线开关保留用户配置。只清理路径表原有两行行末空白。

回归新增对称/不对称多线、单侧单点、宽线和无线的直行保持，航向偏差纠正，单侧线不能提前完成离口，中心回线后推进下一项，实际极性转换与多数滤波链路，缺少/过期前史、窗口外拒绝及直行超时保护。旧圆弧回归在修改前源码也失败：断言写死 18 cm/s，而当前生产配置为 30 cm/s；改为按生产配置检查轮速与原半径，不修改生产速度。

最终验证：`sh test/run_host_tests.sh` 全部通过，两种极性下导航各 344663 项检查，含 AddressSanitizer/UndefinedBehaviorSanitizer；三个模式及丢线/地缝开关回归通过。`pio run`（genericSTM32F103C8）成功，Flash 27240/65536 B，RAM 1448/20480 B；`git diff --check` 通过。README 文字和 Mermaid 同步更新。修正版未烧录、未进行赛道验证。该策略依赖路径窗口及入口航向，窗口内真实曲线、虚线或偏移也可能提前触发直行，并非电阻语义识别。
