## 修复

- `mpu6050_init` 回读 GYRO_CONFIG=0x18，防止错误量程换算。
- 丢弃旧 DATA_RDY，每次校准采样前等待5ms并检查新鲜度。
- 128帧均值绝对值不得超过10°/s，最大最小差不得超过3°/s；配置在 motion_config.h。门槛是保守初值，尚未经过该模块温漂/噪声实测标定。
- 不合格校准不设置ready，主程序保持安全停止；阶段4=采样/新鲜度，5=均值/波动不合格，6=量程回读。初始化失败也保留均值、最后原始值和波动跨度诊断。
- 校准期间须保持车体静止；该检查不能检测所有低速恒转或代替实物确认。拒绝后需放稳并重新上电/复位。
- 本轮不改变路径表、转弯/丢线/自动恢复策略及既有保护，不覆盖开始时的其他修改。
