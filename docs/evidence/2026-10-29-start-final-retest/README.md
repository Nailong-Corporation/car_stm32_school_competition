## 确认原因

初始化已通过：IMU ready=true、阶段0，零偏−5 LSB、跨度2 LSB。控制循环8477次。5次按键/START请求，最终结果REJECTED_FAULT。

首次停车快照为LINE_STOP_TILT，state_before_stop=LINE_IDLE，sample_ms=1426，说明尚未启动即触发拿起停车。最新一次按键0x30为有效单区域窄线，故这次确实是故障锁定拒绝，不是目标线拒绝。读取时当前0xFF歧义不能代替按键时观测。

旧tilt_guard_update在tripped时提前返回；因此读到pitch=56.287°和重力分量是锁存时旧姿态，不能断言当前仍倾斜。即使放平，旧值也不刷新且LINE_STOP_TILT要求复位，导致线上按键仍不能启动。

## 修复

俯仰触发后继续更新姿态，锁存停车保持。当前原始与滤波角度均满足已有40°门槛，且本帧重力范围可信时，允许明确START确认解除俯仰锁定；无须复位、不自动启动。然后按已有连续有效目标线要求启动，START失败不清除停车快照。仍拿起或无效采样时不得解除。只清除TILT，不解除IMU通信/编码器/任务故障。没有新增恢复角度/持续时间门槛。
