## 修改

1. 首项保留65 cm和表速200，将tolerance从5改12，窗口由60～70改53～77 cm。53 cm比记录分支55.35 cm提前约2.35 cm；不通过修改轮程比例伪造里程，也不把65减去灰度前置16 cm。其余表项数值保持。
2. 数字距离非STRAIGHT项：最早允许动作点前完成目标减速。普通转弯参考distance-tolerance，STOP参考distance-min(tolerance,5)，保留其末项提前确认门禁。减速长度D=max(5,(表速²-slow²)/(2a))；slow=min(表速,20)，a=JUNCTION_APPROACH_DECEL_CM_S2=160。区间内按速度平方插值；入口区/候选不超过slow。AUTO、显式STRAIGHT、关闭减速开关及自动恢复区各自原规则保留。
3. 首项200→20对应D=123.75 cm，短首段起步即受目标包络约束：20/40/52/53 cm处上限约104.69/67.53/26.83/20 cm/s。160仅为规划初值，尚无制动标定，目标上限不代表实际轮速；没有取消速度反馈或路口出口保护。
4. entry_trace增加上一周期base、左右目标和PWM，与当前帧实测速度配对核查响应，原128帧、冻结和人工START清空规则保留。相比前版本增加2560 B RAM，固件RAM总量9456 B；不阻塞控制、不输出串口日志。
5. README路径表、减速公式、Mermaid与入口诊断说明同步。

## 航向数据的独立疑点

本轮初始化gyro_z_bias_lsb=-1589.5、采样跨度3450 LSB；读取时raw约-4 LSB。两者差值按16.4 LSB/(°/s)约96.7°/s，若后者为静止读数则会形成严重虚假偏航。首次停车航向5.4833 rad，当前84.9788 rad也不宜直接解释为赛道真实旋转。本轮未改用户此前要求简化的标定门槛，复测上电采样阶段须静止；偏置稳定性与实际车身航向仍待确认。当前后续还锁存俯仰停车/I2C失效，不据此改写首次窗口漏入口的证据。
