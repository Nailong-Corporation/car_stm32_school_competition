## 已实现

- 路径表从距离/容差迁移为路口数、动作、自定义角度、巡航和动作轮速、圆弧开关及可选最终段长度。
- 通用方向无关候选、多帧/位移确认、计数一次、锁定与时间/位移离口；非目标路口直行且不推进索引。真实失线与孤立骤变不计数。
- 移除距离触发 STRAIGHT、距离窗口、旧出口投影交接和自动续跑。最终 STOP 确认后停车并分派一次回调。
- 转向保留 IMU 航向、非负轮目标和灰度捕线；目标角与连续中心出口线共同确认，错向/过转/动作与离口超时停车。动作双轮目标上限受表内 turn_speed 限制。
- 入口实测轮速过高进入 BRAKING；撤去正向输出，500 ms/2 cm/航向超限停车，不高速强转。
- 独立 braking_planner 计算速度包络和所需减速度，向上加速度/jerk 限制，安全上限下降直接钳低。只有目标路口前最后一段启用，距离走完不补计，搜口 2000 ms/12 cm 上限。
- IMU 固定静止窗口中位数校准，中央 90% 波动及偏置初值门禁；新鲜数据/通信、饱和和过大角速度拒绝；保留俯仰保护。
- 反向制动默认 0；独立短路制动接口仅验证 HAL 请求状态，不接入自动导航。

## 参数与实车边界

默认路径保持 LEFT / LEFT / LEFT / STOP、巡航目标 200 cm/s 和圆弧开关。每项 junction_count=1 为迁移初值，实际赛道需逐口复核；turn_speed=16 cm/s 是未标定动作轮速上限。3000 ms 动作时限保持当前源码值，不能引用旧文档的 4500 ms。转角、去重和入口制动界限均需低速实测。

所有 final_segment_length_cm=0，BRAKING_CALIBRATION_CONFIRMED=0、BRAKING_SAFE_DECEL_CM_S2=0：未伪造从离口到灰度触发点的测量或安全减速度。合成测试的 30 cm/s² 不写入生产配置。默认关闭机会式降级，按计划待主方案实测后另行实现。
