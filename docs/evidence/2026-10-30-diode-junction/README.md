## 修正

旧代码没有区分“转弯已经确认出口后的离口”和“直行图形仍在寻找出口的离口”，单一区域侧边（0x0f、0x03 等）可直接触发位置 PID，且可被用作去重证据。新的直行离口需居中 |position|≤2、单区域、最多3路；在连续3帧合格之前始终冻结位置 PID，保持入口航向。侧边、中心宽区域及多区域不解锁、不补计。转弯离口已确认出口，继续允许横向窄线恢复，保留此前修复。

直行 CLEARING 使用外轮限速混合，位置/航向差值不再使某一轮超过 pass 上限；倒数第二口确认后的50 cm/s限速持续有效。居中出口连续50 ms/2 cm去重完成后恢复 FOLLOW，计数保留为1、最后一段激活，下一路口为第2口才执行LEFT。

直行离口从进入或最近连续3帧合格出口起，400 ms/8 cm任一到期即新故障12 CLEAR_LINE_LOST；先判期限再接受恢复，侧边、孤立居中帧不续时。保留原1500 ms/20 cm总离口限制，不扩大失线盲行范围。
