# 出口 PID 接管与 IMU 初始化总线恢复（2026-10-30）

## 依据与边界

用户反馈首弯 100% 失败、灰度扫过线仍未开启巡线，要求修复出口控制和经常发生的 IMU 初始化失败。此前只读证据见 `../2026-10-30-first-turn-overrun/README.md`：首弯在 EXECUTING 3000 ms 超时，曾捕获 0x01 窄线，最终未确认出口；IMU 初始化阶段 2 失败而使用编码器。该读取按用户要求未检查固件一致性，本次没有新增硬件读取/写入、没有烧录/复位/操作电机。

## 软件修正

- 捕线后原先将位置 PID 与剩余角度项叠加，并强制保持原转向；位置已要求反向时仍可能继续原转向。新回归在修改前的控制逻辑上因反向纠偏断言失败（`capture-before.log`）。现在达到捕线角且出现单区域窄线时，外轮目标立即不超过 min(turn_speed,16)，位置 PID 接管非零纠偏；不叠加剩余角度、不强制原方向。圆弧捕线后也退出几何轨迹控制。
- 仅在线位置为零、PID 输出接近零且角度不足时，允许最多 1.2 cm/s 的补角半差；这是为连续中心出口线保留有界角度完成能力，不覆盖位置纠偏。实际角速度阻尼保留。转角/出口确认、错向/过转/动作超时不放宽，自定义角门禁保留。
- 捕获后再失线/歧义从最近合格捕获起 400 ms 或 8 cm 任一达到停车，故障号 11 EXIT_LOST。中断后连续三帧合格捕获才能刷新计时和距离，孤立窄线不能无限续时，先检查期限再接受恢复。未捕到出口仍受原动作时限约束。
- 旧 I2C 驱动只做外设复位。按 ST ES096 §2.8.7，STM32F103 模拟滤波器可能锁定 BUSY，单纯外设/系统复位不能清除，需要 SCL/SDA 转换。现在只在上电初始化和探测重试中，以开漏释放总线、必要时最多 9 个 SCL 脉冲、SDA/SCL 逐项电平转换/检查、恢复复用开漏后复位初始化。每次电平等待有界；持续低电平记阶段 9。旧逻辑在模拟 BUSY 锁定的回归上失败（`imu-before.log`）。
- 新增初始化诊断：恢复次数、最后 HAL 状态/错误、WHO_AM_I、释放后总线电平（bit0 SCL / bit1 SDA）。双地址探测、静止质量门限、失败锁定编码器降级及运行期间超时保护保留。初始化正常路径每次恢复增加约 5 ms；不在运动中恢复或校准。
- 沿用编码器方向、距离与航向比例、路径表及制动模式；同步 README 文字与 Mermaid。

ST 主来源：https://www.st.com/resource/en/errata_sheet/es096-stm32f101x8b-stm32f102x8b-and-stm32f103x8b-mediumdensity-device-limitations-stmicroelectronics.pdf
