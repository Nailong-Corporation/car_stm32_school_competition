# 首弯后在线动作超时：普通转弯凭出口线完成（2026-10-30）

## 用户要求与证据

用户反馈首弯后在线上停止，并明确补充“灰度传感器已经找到线了，就应该继续了”。最终规则按用户补充实施：普通转弯找到连续有效出口线后即继续巡线，不追加200 ms/2 cm等待，不要求估计达到90°。自定义角门禁独立保留。

沿用ST-Link只读授权，GPIOB ODR=0、STBY低，短暂停核读取SRAM4096 B后立即恢复；未读取Flash、未检查固件一致性、未复位/烧录/请求START/操作电机，未冻结看门狗。按读取前保存的read-time.elf解码，控制器与诊断两份128字节stop_snapshot一致；不宣称板上二进制一致。ram.core是无CPU寄存器的离线SRAM容器。

- 最近START已接受；首弯index0、junctions_seen=1，EXECUTING持续3000 ms后ACTION_TIMEOUT，速度故障NONE。
- 停车帧0x08，GRAY_VALID、单区域、position=-1；不是丢线。清零前目标12.6358/16，反馈13.0961/13.8573 cm/s。
- 编码器估计转角-0.7361276 rad（约42.2°），不能满足此前约90°角度门槛。末段trace显示持续在0x18/0x08线上前进，但路径状态未完成。
- 本次IMU静止质量校准阶段7失败，5个窗口、中央跨度1193 LSB（门限64），初始化bias=-118.5，1578 ms锁定编码器航向。不是阶段2总线探测失败。未放宽校准门限或修改编码器尺度；实际车体角度不能由当前降级估计确认。

## 修复

LEFT/RIGHT及普通闭合转弯进入捕线阶段（原最小0.70 rad）后，连续3帧居中有效单区域窄线（位置绝对值≤2、至多3路）即完成动作进入CLEARING，位置PID继续低速巡线。不等估计90°，不再要求额外100/200 ms或0.5/2 cm动作完成证据；普通离口50 ms/2 cm只控制解锁计数，不阻止PID接管。此规则对健康IMU和编码器航向一致。

满角度旧出口确认路径保留。CUSTOM_TURN仍要求原角度/出口证据；动作期限在判出口前检查，不允许到期后在线豁免成功。无线、歧义、侧边、宽图形、采样中断不能满足新三帧证据。错向/过转/速度/调度/失线边界保留。诊断turn_exit[i].line_confirmed_exit记录普通转弯未满目标角但凭出口线完成；这不是实测精确90°的证明。
