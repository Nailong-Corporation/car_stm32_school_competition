48 点循环 trace 只保留 6657–7597 ms（20 ms 间隔），全部 mask=0x00。约 92.26° 时左右目标 16 / 13.956 cm/s，已输出与原左转相反的右向角度纠偏；此时反馈 14.182 / 14.755 cm/s，尚未匹配目标轮差。末段估计转角逐渐回到约 88.15°，最后因动作超时停车。无可靠线时该段为角度控制，不是位置 PID 循线；相近非零双轮目标使车辆继续前进。

不能证明此前是否曾有连续居中出口线、哪一帧清除了出口候选，或实际几何过转量。早期转弯灰度历史已被循环覆盖。也不能从当前停车后实时灰度 0xC0/position=6 推断失败瞬间灰度。

## 结论与边界

本次可确证：曾接收单侧窄线，但没有完成出口确认；后期无线仍维持非零低速前进，最终动作超时。并非“未见任何灰度”或“完全没有纠偏目标”，也不是软件过转保护停车。IMU 不可用和实测轮差跟随不足是后续定位必须保留的因素，不能仅据此确认为物理过转根因。
