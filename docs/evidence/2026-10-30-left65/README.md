## 修正及边界

检查发现：数字距离项即使开启 90° 圆弧，形状匹配后仍进入普通候选，等待至少 3 帧和 0.1 cm；仅 AUTO 立即执行。这不符合圆弧见路口即进入动作的要求。

`src/route.c` 修正为 AUTO 或启用90°圆弧的转弯在形状匹配当帧 `accept_step()`。数字项仍先通过原距离窗口、STRAIGHT 后距离保护和目标分支形状检查；原骤变强制入口保持。普通非圆弧转弯、最终 STOP 候选确认、出口/离口及故障保护保持原规则。README 流程图和文字同步。

这消除了一个可以复现的入口延迟，不能证明已解决本次首次漏触发：首次快照没有记录匹配形状。若实际见路口时仍在窗口外，或滤波后没有符合入口形状，本修正不会强行转弯。未扩大窗口或改为按里程盲转。
