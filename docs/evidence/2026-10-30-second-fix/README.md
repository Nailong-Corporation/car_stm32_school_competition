## 最终实现

保留第二项{190,16,LEFT,200,0,false}和其他表项，不通过扩大窗口或更改里程比例修复。

生产JUNCTION_REQUIRE_DIRECTION_EVIDENCE=1：

1. 数字左右转的非零骤变须当前帧匹配目标方向的路口形状；反侧/无中心分支噪声不再凭骤变按表转。
2. 纯丢线须本窗口内连续至少2帧匹配目标侧分支，最后一帧距当前≤100 ms、前进≤1.5 cm；仍受原相邻采样、连续窄线及骤变条件限制。此机制允许已扫过的短分支后丢线，但不能把丢线本身当路口。
3. 窗口外不建证据，离窗、倒退、过期/超距、采样间断和反方向分支清除；START/正常切段/跟随阶段自动恢复清除。AUTO本来不使用骤变强制，普通候选及圆弧当帧形状入口保持原规则。
4. 动作/离口时限、出口回线、速度反馈和当前丢线停车开关不改。减速仍在174 cm窗口起点前降至目标20；纯丢线等待目标时保持原异常策略，不越过206 cm距离上界。

数字窗口内有多个同形同方向路口时，此规则仍不能从8位灰度语义识别目标，需要准确几何约束或额外标记；本次不作保证任意支路都能区分的承诺。
