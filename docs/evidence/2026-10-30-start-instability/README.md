# START 不稳定现场只读检查（2026-10-30）

## 授权与操作边界

用户选择保留现场并读取只读诊断，不复位、不烧录、不请求启动/停车、不写控制变量。
使用 OpenOCD/ST-Link，1000 kHz SWD；先读 GPIOB ODR=0x413，PB5 STBY 低，才短暂停核读 SRAM 前4096B，随后请求 resume 并 shutdown。没有冻结看门狗、读取Flash或核对固件一致性。目标电压约3.237V。原始日志 `openocd.log`，数据 `ram.bin`；日志不含完整的dump耗时/寄存器输出，不据此声称精确暂停时间。

## 布局适用性（重要）

- 读取前保存本地 ELF `read-time.elf` 与 `symbols.txt`，没有重构建覆盖它。
- 直接按该ELF解析结果含非法枚举和布尔、错误时基，见 `decoded-local-layout.txt`；该解析作废，不能当成真实启动故障数据。
- 本地最新 LineFollow 含上一轮新增角速度字段4B，总大小2716B。本次RAM与“删去该字段、总大小2712B”的旧布局候选吻合，诊断地址候选为0x20000cb8，而当前本地ELF是0x20000cbc。
- `legacy-layout-model/` 是离线重建的**类型布局模型**，不是从板上提取的固件，也不是已经确认的板上ELF。仅删去角速度字段，使用ARM短枚举构建，静态断言尺寸。`decoded-legacy-candidate.txt` 按该模型和候选地址解析；`ram.core` 是SRAM的离线ELF容器，不含CPU寄存器。
- 诊断与控制器内两份停车快照逐字段相符，当前采样时刻/计数/里程亦相符，增强布局候选可信度；没有Flash比对，不能证明板上具体版本。结果以下述布局适用为前提。
