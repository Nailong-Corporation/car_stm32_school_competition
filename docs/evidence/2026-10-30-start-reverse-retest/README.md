## 软件机制与未知项

生产换算每计数约0.020782847 cm，轮速一阶滤波tau=0.030 s。
静止基线上5 ms一个反向计数，滤波轮速为
`-(0.020782847/0.005) * 0.005/(0.030+0.005) ≈ -0.593796 cm/s`。
所以旧小于-0.5立即锁定规则对单计数敏感，即使该轮目标为零。
原始计数绝对值9不是增量9，也不能证明实际连续倒转。
没有完整的停车前计数历史，不能确定该次负反馈是抖动、回弹、外力还是实际方向/信号异常。

## 修正

不改电机/编码器极性、不取绝对速度、不禁用反向检测，增加独立左右有界确认：

- 低于-0.5 cm/s立刻撤去双轮驱动，复位双轮速度PID，不积累PWM。
- 同一轮连续50 ms或该段负反馈积分达到0.1 cm任一触发REVERSE锁定。
- 达到-5 cm/s当帧锁定；零目标同样检测。
- 实际dt累计；回到阈值内才清除该轮候选，左右不转移证据。
- 瞬态待确认输出禁用但控制/路径状态继续，不启动新一轮、不重置路径、不解除已有STOPPED锁定。
- 确认故障仍由人工排除原因后复位；禁止START清除编码器锁定。

参数均为待实测初值。候选期间为STBY低待机，不是已验证的制动力；
可能延迟低速真实反向的锁存，但确认期间不驱动。间歇小幅负反馈可能多次抑制输出，
不能宣称硬件故障已修复或一定能启动。路径、丢线、计数跳变和控制任务保护仍保留。
