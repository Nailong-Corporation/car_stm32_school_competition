# 再次无法启动：未收到START与当前无线（2026-10-30）

## 操作边界

沿用用户只读现场诊断授权；不复位、不烧录、不发送START/STOP、不写控制变量、不操作电机，不读Flash核对版本，不冻结IWDG。

首次运行态STBY预读返回0，短暂停核保存SRAM4096B后请求resume。后续运行态寄存器/SRAM补读出现成片全零，弃用这些读数，不能据此判断GPIO配置/电平。

再次短暂停核同步读取GPIO配置/输入/输出、按键消抖SRAM及诊断头，保存第二份SRAM后请求resume并结束连接，见 `halted-input-confirm.log`。未增加阻塞等待，不声称精确暂停耗时或绝对无复位风险。
