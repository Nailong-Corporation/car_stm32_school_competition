- 旧源码到目标角但无线仍命令固定单轮强转；新增回归首先在左右目标应相等的断言失败，退出134，见 `before.log`。

- 保留角度/出口/错向/过转/动作与离口限界。没有开启反向制动或负轮速，没有修改路径表和极性。
