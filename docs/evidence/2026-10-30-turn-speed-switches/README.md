# 2026-10-30 转弯速度开关验证

本次按用户要求恢复入弯减速、出弯快速加速，并加入编码器轮速反馈控制的反向 PWM 减速。三个生产开关均为 1，参数见 `include/motion_config.h:188`。工作区原先已有未提交修改，保留这些修改；未烧录、未运行电机。

## 实现

- 减速：所有非 STRAIGHT 表项使用原 5 cm / 20 cm/s 包络；普通转弯动作外轮上限 20 cm/s，圆弧以轴中点上限分配轮速。关闭减速开关恢复表速动作；恢复窗口的独立保护仍保留。
- 加速：出口确认后立即预看下一段，以 400 cm/s² 提速。快速阶段跨切段延续，达到当时规划目标或开始新动作后结束；START 保留 1 s 包络。关闭后本段离口使用本段表速及普通 160 斜率，切段后才使用下一段表速。
- 制动：非零正目标且实测正向超速超过 3 cm/s 时输出 `-min(60, 4*(measured-target-3))`。接近目标即撤销，制动不累积积分；速度目标仍非负。零目标、禁用和故障仍使用原停车语义。普通 PWM 模式拒绝反向输出。
