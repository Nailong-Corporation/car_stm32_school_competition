# 首次 LEFT 出口线扫过后的停车：只读现场证据

2026-11-02 用户授权 ST-Link 只读读取。保存当前本地 `read-time.elf` 后，以 OpenOCD 1 MHz SWD 短暂停核：GPIOB ODR=0x713，PB5/STBY 为低；读取 SRAM 起始 12 KiB，随即请求 `resume` 与 `shutdown`。没有复位、烧录、写控制变量、发送 START、读取 Flash 或冻结看门狗。日志见 `openocd.log`。`ram.core` 仅将本次 `ram.bin` 放进历史离线容器相同的 4 KiB ELF 头，供 GDB 按本地 ELF 布局读取；不含目标寄存器。没有比较板上 Flash，本地布局适用性以控制器/诊断两份 148 B 停车快照逐字节一致、当前枚举和轮径 6.5 cm、轮距 14 cm 合理为依据，仍不能证明板上二进制完全一致。

## 读数

- START 已接受。首次 LEFT，索引 0、路口计数 1；在 `ROUTE_CLEARING` 中以 `LINE_STOP_LOST` 停车，路径失败码和速度故障均为 NONE。停车时刻 5362 ms，距最后稳定线正好 400 ms；离口前进 4.59 cm 但未连续确认合格线，所以索引未推进。控制器停车快照与 `g_diagnostics.stop_snapshot` 一致。
- `turn_exit[0]` 记录 4837 ms 在估计转角 0.793 rad 时首次捕获最左路 0x01，目标左/右 9.12/16 cm/s；由 `turn_trace.csv` 对照，右轮反馈约 39 cm/s。4897 ms 于估计 0.875 rad、0x10 中心线确认后进入 CLEARING；随后灰度 0x20→0xc0→0x80→0x00 向右扫出传感器。4902 ms 右轮反馈仍约 33 cm/s，尽管位置纠偏已要求右轮约 5.5 cm/s；4962 ms 右轮仍约 28 cm/s，线于 4972 ms 已不可见。`navigation_trace.csv` 提供停前 128 个 5 ms 控制周期的原始和滤波灰度、左右反馈及阶段。
- IMU 初始化阶段 9 失败，587 ms 已锁定编码器航向来源；停车不由 IMU 故障或过转触发。0.793/0.875 rad 是使用沿用的距离比例 2.15 与航向比例 0.77、新轮尺寸推得的估计角，**不等于已校准的真实转角**。

源码机制：此前 EXECUTING 在首次捕线前允许外轮目标达到表内 50 cm/s，捕线后才将目标压到 16 cm/s。现场首次捕线时反馈仍近 39，确认中心线后反馈仍近 33，降速和反向纠偏没赶上线在探头上的横移。新回归在旧代码上以未捕线外轮目标超过 16 的断言失败（`pre-fix-test.log`）；修正后非直行动作从开始即给外轮目标 `min(turn_speed,16 cm/s)`，保留原中心出口连续确认、低速 CLEARING、失线/角度/反馈/时序保护。无反向制动，入口轮速门禁仍按表内 turn_speed，**目标提前降低不保证真实轮速一定足够慢**。改变转弯前实际轮速、机械探头前置距离及未标定编码器角度都会影响实车效果；没有从离线轨迹证明新固件一定能抓住线。

`decode_trace.py` 仅按归档 ELF 的 `ptype /o` 偏移从 `ram.bin` 解码，CSV 按环形索引恢复时间顺序。`host-tests.log` 和 `pio-run.log` 为改后主机逻辑与交叉构建；未上传或操作电机。重新上赛道前需架空确认实际轮速降到安全区间，尤其检查动作入口与首次捕线时左右反馈；再低速验证扫线方向和 IMU 降级时的实际转角。若仍丢线，保留新的快照及轨迹确认入口惯性或几何问题。
