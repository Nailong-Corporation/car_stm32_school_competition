## 补充修正

1. BRAKING_SAFE_DECEL_CM_S2从120改为40 cm/s²，更早安排降速。50→16的模型减速距离从9.35增至28.05 cm，不含原2+3 cm余量及35 ms软件预留。40是更保守的待实测初值，并非宣称由一条快照测得了安全制动力。路径表65/70/50/70、节点数/动作/巡航速度、所有其他硬件标定与极性保持。
2. 速度内环单轮反馈超过本轮目标3 cm/s即撤其正向PWM、清该轮PID历史；否则加速期正积分可在降目标后继续推车。旧代码以积分上限10、目标15.2、反馈32.1849输入仍有正输出，新增回归integral-before.log失败退出134。现场停车已清PID、旧轨迹没有PWM/积分，所以只能确认软件机制，不声称现场积分数值已被读到。
3. 显式反向制动分支仍优先，生产反向开关保持0，不请求负轮速或调用短刹。双轮PWM零仍由motor_apply转STBY低待机，单轮零输出的原电气行为保持，不能声称已验证制动力。
4. 保留上次统一距离边界及反馈延迟预留；原60 cm原因13停车、实测16 cm/s转弯入口、搜口/丢线/编码器/任务/转角保护保持。若更弱减速条件仍不能满足，继续停车，禁止以延后保护或盲转掩盖。
5. 新快照增加清零前左右PWM与速度积分（176 B），每周期导航轨迹新增左右PWM（64 B）。布局改变，今后读取须保存当时ELF。本次旧ELF及SRAM已独立归档。
