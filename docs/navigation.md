## 编译开关与普通电压控制

`include/motion_config.h` 使用两个独立编译开关，当前均为 1，修改后重新编译；不支持行驶中动态切换。2026-10-22 新增 `PRESET_ROUTE_ENABLED`，可设为 0 在编码器双环下单独测试巡线。

- **0**：不初始化/读取编码器，不运行里程、速度环、距离路口导航或路径 STOP callback；状态为 `ROUTE_DISABLED`。白线位置 PID 直接输出左右 PWM，通过占空比调节电机平均电压，轮速保持开环。尺寸参数为 0 不影响该模式的启动。
- **1**：启用编码器和双环；保留尺寸标定门禁和反馈异常停车。厘米路径另由 `PRESET_ROUTE_ENABLED` 选择。

`PRESET_ROUTE_ENABLED=0` 为仅巡线：忽略传入路径表和回调，不校验路径、不采用表内速度，不执行预设转向、距离窗口、路段超时或路径 STOP，状态保持 `ROUTE_DISABLED`。编码器仅巡线使用 `LINE_FOLLOW_SPEED_CM_S=12.0f` 作为基础目标速度，保留弯道降速、双轮速度环、干扰航向保持、400 ms / 8 cm 超限停车、任务/反馈故障和明确停止。全白、宽线和多区域一律进入干扰保持，不保证分岔处的分支选择。PWM 模式继续使用独立 PWM 参数。

`PRESET_ROUTE_ENABLED=1` 为本文的预设厘米路径、路口 FSM 与 STOP callback，必须同时配置 `ENCODER_CONTROL_ENABLED=1`，否则编译报错。两个开关都只允许 0 / 1。

PWM 模式的参数独立使用 PWM 单位：正常基础 255、最大偏差时基础 40、干扰基础上限 35、上升斜率 255 PWM 指令/s（1 s 达到居中目标）、位置 PID 8/0/0.08。输出限于非负且不超过 255（255 标尺），这些 PWM 参数不用于当前编码器速度目标。不把路径表中的 cm/s 数字直接当作 PWM。

PWM 模式要求明确启动且连续 3 帧有效窄白线。遇到无白线、宽线、全白或多区域时，冻结位置 PID，不提高基础 PWM，保留最近的有界 PWM 差值并在剩余异常预算内衰减；这不具备测量航向或纠正偏航的能力。恢复需连续 3 帧，重置 PID 历史；最后稳定白线起 400 ms 停车，孤立有效帧不续时，先检查截止再接受恢复。没有编码器，不使用 8 cm 距离限额，也不进行厘米路径动作。PB10、调试停止、任务时序检查、IWDG 和上电停止保留。

2026-10-23 按用户要求只保留 `genericSTM32F103C8` 一个环境：`pio run` 和一键上传都遵循头文件，不通过其他环境覆盖模式。模式与标定见 `include/motion_config.h`，颜色见 `include/control_config.h`。固件统一输出到 `.pio/build/genericSTM32F103C8/`。`g_diagnostics.encoder_control_enabled`、`preset_route_enabled` 表示实际模式；关闭编码器时里程和速度保持未测量的 0 值，不能解释为实际零速。

主机测试脚本分别编译 PWM 仅巡线、编码器仅巡线、编码器预设路径三个组合。PWM 测试不链接 `odometry.c` 或 `speed_control.c`；编码器仅巡线测试不链接 `route_table.c`，并检查传入路径表不会产生动作或回调。下面的双环/里程内容适用于编码器开关为 1，路径/路口内容还要求路径开关为 1。

## 单位与双环

- 白线位置：权重单位，S0…S7 为 −7…+7；`error = position - 0`。
- 位置 PID 外环输出：左右目标速度的半差，单位 cm/s。
- `left_target = base + correction`，`right_target = base - correction`；正修正期望向右转。
- 轮速 PID 内环：每轮独立，以“目标 cm/s − 编码器测量 cm/s”为误差，输出 PWM 指令。
- 目标速度限于 0…40 cm/s；每次 START 使用 `min(1, 启动累计实际 dt / 1 s)` 的基础目标包络。居中直线在 1 s 内达到表中目标；恢复和路段切换的上升斜率为 160 cm/s²。降速/停车不等待斜坡，不输出倒转命令。
- PWM 沿用 0…255 标尺、运行上限 255，最终由 TIM3 ARR=6399 映射成 CCR。编码器模式目标 40 cm/s 不等于 PWM=255，实际加速和轮速达成时间仍需测量。

`pid_update_bounded()` 支持不对称输出边界和前馈：速度内环按 `前馈 + PID` 总输出是否越过 0…255 决定积分是否接受，避免只限最终输出却继续积累积分。位置环使用对称边界；两类 PID 都有积分限幅、微分滤波、非法值拒绝和历史复位。

外环初值 P=1.8、I=0、D=0.025；内环 P=2、I=8、D=0，前馈为 `3 × target_cm_s`。轮速低通时间常数 30 ms。它们都是软件初值，实际应先标定/调试速度内环，再调位置外环。

停车、启动、干扰后稳定恢复、路口动作切换会清理相应 PID 历史。干扰期间位置 PID 不更新，速度内环继续工作；不是直接沿用上一 PWM。

## 编码器与标定入口

左轮 PA8/PA9 对应 TIM1_CH1/CH2，右轮 PB6/PB7 对应 TIM4_CH1/CH2。`encoder_init()` 使用 `TIM_ENCODERMODE_TI12`，PSC=0、ARR=65535，两输入直接映射、IC 滤波值 6、无内部上下拉，启动 CH1+CH2。TI12 在两相边沿四倍频计数，见 [ST HAL](https://github.com/STMicroelectronics/stm32f1xx-hal-driver/blob/master/Src/stm32f1xx_hal_tim.c)与 [RM0008](https://www.st.com/resource/en/reference_manual/cd00171190.pdf)。滤波参数与信号波形仍需实测。

换算：

```text
left_cm_per_count  = π × left_diameter_cm  / left_counts_per_wheel_rev  × ODOMETRY_DISTANCE_SCALE
right_cm_per_count = π × right_diameter_cm / right_counts_per_wheel_rev × ODOMETRY_DISTANCE_SCALE
Δleft_cm  = signed_left_counts  × left_cm_per_count
Δright_cm = signed_right_counts × right_cm_per_count
Δdistance_cm = (Δleft_cm + Δright_cm) / 2
Δheading_rad = (Δleft_cm - Δright_cm) / wheel_track_cm
wheel_speed_cm_s = Δwheel_cm / actual_dt
```

## 路径存储与停止回调

`include/route.h` 定义 `Action` 枚举及 `RouteStep` 结构体，`src/route_table.c` 的只读表编译进固件 Flash：

```c
typedef enum { LEFT, RIGHT, STRAIGHT, STOP } Action;
typedef struct {
    float distance;   // cm
    float tolerance;  // ±cm
    Action action;
    int speed;        // cm/s，不是 PWM
} RouteStep;

const RouteStep route[] = {
    {104.0f, 8.0f, LEFT, 40},
    {131.0f, 8.0f, LEFT, 40},
    {60.0f, 5.0f, LEFT, 40},
    {39.0f, 5.0f, LEFT, 40},
    {70.0f, 5.0f, STOP, 40}, // 仍要求路口确认
};
```

表中距离和容差保留现有设置，保留用户已设定的各段目标 40 cm/s，并同步轮目标上限，未重新测量赛道。首段以明确启动时的里程为零；下一段以“上一动作完成并离开路口消抖区”的位置为零，不是起点累计里程。表项要求正距离、有限且小于距离的非负容差、0…40 范围内的正目标速度；最后一项必须 STOP，STOP 不能位于表中间。启动时会重置路径索引到 0，不自动续跑一半路径。

`include/motion_config.h` 中 `ROUTE_REPEAT_COUNT` 为执行总轮数，默认 `0U` 无限；`1U` 单轮、`2U` 两轮。范围 0…UINT32_MAX，修改后重新构建。`route_start()` 清零 `completed_laps`；每轮末项 STOP 在距离窗口内确认后累计一次（无限模式计数饱和）。未到最后一轮时，末项 STOP 从入口判断起映射为 `ROUTE_REPEAT_ACTION`，当前为 LEFT（用户确认末端左转闭合），可改 RIGHT / STRAIGHT。转角、出口和离口仍使用原确认与保护，完成后索引回到 0，保留出口方向位移建立首段基准。不停车、不重置加速历史、不分派 callback；有限轮数的最终 STOP 才进入 FINISHED 并停车回调。末项不允许早于标称距离前 5 cm 进入候选或骤变转向；当前 219±16 cm 的末项最早 214 cm 确认，正常窄线下从 214 cm 开始减速。主机模拟不能证明真实闭合效果。

所有动作都要求 `distance - tolerance <= 当前路段里程 <= distance + tolerance`。STOP 不因里程单独到达而成功；没有路口并越过距离窗口上界则以 `LINE_STOP_ROUTE` 停车，不调用成功回调。

按用户最新要求，整段行驶直接取消时间限制：不设置固定 15 s 或按长度/速度计算的预算，不因路段经过的时间而失败停车。启动或推进下一项时仍建立里程基准，并保留 `segment_ms` 用于 `route_elapsed_ms` 诊断；经过毫秒时基回绕也不会触发路段时间停车。越过距离窗口上界、路口候选确认 100 ms、动作 4500 ms、离口独立 1500 ms、丢线/反馈/任务保护仍独立生效。

`g_diagnostics.route_failure` 锁存具体原因至下一次 START：0 无失败、1 非法配置/输入、2 越窗、3 已停用（旧路段超时）、4 候选确认超时、5 动作/离口超时、6 过转、7 反向转弯。结合 `stop_reason`、`route_state`、`route_index`、`route_progress_cm`、`route_elapsed_ms` 定位。`route_elapsed_ms` 为采样当前时间减路段起始时间，停车后仍增长；它不是锁存的停车时刻。可按 START 再启动只排除了部分锁定故障，不能直接判定具体停车原因；整段行驶计时已不再触发停车。

`RouteStopCallback` 为 `void (*)(size_t step_index, void *context)`。最终轮 STOP 确认后路口状态进入 `ROUTE_FINISHED`，控制器立即清空目标和 PWM 命令、复位各 PID。主循环下发 `motor_stop()` 后调用 `route_dispatch_stop_callback()`，先锁存一次性标志再调用用户代码，重复分派及回调重入都不会重复执行。

默认回调在 `src/main.c`：

```c
void route_stop_callback(size_t step_index, void *context)
{
    (void)context;
    ++g_diagnostics.route_stop_events;
    g_diagnostics.route_stopped_step = (uint32_t)step_index;
}
```

回调属于主循环任务，不在 ISR 内；应保持短小，不允许阻塞延时、长串口输出或重新使能电机。任务耗时检查包含回调。按键停止、超时与故障不会生成成功回调；任务在分派前已超时则取消待分派事件。

## 路口有限状态机

| 状态 | 条件与动作 |
| --- | --- |
| `ROUTE_FOLLOW` | 窗口内 LEFT/RIGHT 整排骤变优先直接进入 EXECUTING；其余正常目标线双环控制；表内标称路口前 5 cm 开始按速度平方与剩余距离的包络减速，到标称位置基础目标不超过 10 cm/s（不扣容差），窗口内合适形状才进入候选 |
| `ROUTE_CANDIDATE` | 同帧中心+目标分支至少 4 路；LEFT/RIGHT 另接受中心+分支至少 3 路的窄区域，或最近连续中心线后至少 2 路单一目标侧边缘分支；降速保持航向 |
| 强制转弯入口 | 前一帧属于连续 3 帧窄线，相邻帧间隔 ≤15 ms；本帧全丢线，或至少 2 路目标且明显整排变化，即按表 LEFT/RIGHT 同周期执行，不检查仍在线、中心/分支或额外候选确认 |
| 普通候选确认 | 连续至少 3 帧，确认期间前进至少 0.1 cm，100 ms 内、仍在窗口；图形消失清候选，但不刷新丢线基准或路段时限 |
| `ROUTE_EXECUTING` | LEFT/RIGHT 内轮目标 0、外轮 16 cm/s，无出口线且转过 1.25 rad 后外轮降至 6 cm/s；转过 0.70 rad 后单一窄出口线由位置 PID + ±90° 航向捕获，基础速度不超过 6 cm/s；STRAIGHT 保持入口航向 |
| 转弯退出 | 期望方向至少转过 1.30 rad，或至少 1.25 rad 且单一区域窄线连续 50 ms、净前进至少 0.25 cm；最终均须中心窄目标线连续 3 帧；超过 2.1 rad 或反向转过 0.35 rad 停车 |
| 直行退出 | 从确认位置起前进至少 3 cm，同时中心窄白线连续 3 帧 |
| `ROUTE_CLEARING` | 恢复目标线 PID，立即预看下一段目标并按 160 cm/s² 加速；下一段低速与短段起点减速包络仍生效。再离开至少 3 cm 并连续 3 帧窄目标线后消费下一项、重建路段基准，速度连续 |
| `ROUTE_FINISHED` | 最终轮 STOP 路口确认，停车并等待主循环分派一次性回调 |
| `ROUTE_FAILED` | 越过窗口、候选超时、动作 4500 ms、离口独立 1500 ms、异常方向等；停车并保留具体原因 |

LEFT 分支要求 S0/S1 至少一路白；RIGHT 要求 S6/S7 至少一路白；STRAIGHT 和 STOP 接受任一侧分支。L 弯时序确认必须先在同一距离窗口连续 3 帧得到中心窄目标线，历史有效期小于 250 ms、前进距离不超过 1.5 cm；随后连续目标侧分支并前进 0.1 cm 才能触发。上述普通候选拒绝单次中心噪声、过期中心、无中心历史的两路侧边线、单个边缘点和反向分支。STOP/STRAIGHT 不使用该放宽规则。当前没有图案语义识别或路口类型学习；阈值需根据真实线宽、传感器高度和阵列跨度标定。

整排骤变优先于普通候选、正常位置 PID 的在线判断，方向只取当前表项。使用极性转换和三帧多数滤波后的 `line_mask`：全丢线直接命中；其他观测须至少 2 路目标，并满足翻转至少 4 路、目标数增加至少 2 路、翻转至少 2 路后为宽线/多区域，或窄线位置跳变至少 4 权重之一。配置为 `JUNCTION_ABRUPT_CHANGED_BITS`、`JUNCTION_ABRUPT_WIDTH_GROWTH`、`JUNCTION_ABRUPT_POSITION_JUMP`。不要求同帧中心/目标侧分支，不再等待 3 个候选帧和 0.1 cm，仍在线或反侧分支也按表转；逐帧平滑横移 2 权重不会命中强制分支，普通形状候选仍独立生效。历史只取相邻有效周期，切段/START 清空，单个边缘目标点不命中。骤变在窗口外不会锁存到窗口内；STOP/STRAIGHT 保留原确认规则。

强制动作仍有原来的出口捕获、转角/时限与离口要求；早到中心线不能在转角不足时取消动作。进入动作前，已到期的丢线/距离及故障停车优先；执行后使用动作 4500 ms 与离口独立 1500 ms 预算。诊断 `route_turn_forced` 保持至下一段或 START，可与 `route_state`、`route_turn_rad` 一起核对。骤变只是形状启发式，不能识别真实非曲线：窗口内虚线或元器件图形突然变化也可能触发，需实车验证。

原配置基础 6、半差 4 cm/s，左右目标 2/10 cm/s，在 14.5 cm 轮距下理论角速度为 `8/14.5 rad/s`，90° 约需 2.85 s，超过原动作与离口共用的 2.5 s。2026-10-24 基础目标由 6 提高到 8 cm/s，转弯半差等于基础值，左转目标为 0/16、右转为 16/0 cm/s，理想半径从 10.875 cm 缩小为半轮距 7.25 cm；接近 1.25 rad 后目标改为 0/6 或 6/0 cm/s 找线。本次增加出口捕获：约 40° 后的单一窄目标线即更新位置 PID，以最高 6 cm/s 基础目标前进找正，叠加 `8 × (入口 ± π/2 − 当前航向)` 的速度半差，再统一限幅；目标始终非负。无可靠出口线则复位位置 PID 并继续单轮扫线；多区域和全目标线不能用于捕获。动作预算 4.5 s、确认出口后独立离口预算 1.5 s，退出仍要求转角和连续中心目标线，并保留最大转角/反向保护。较低表内速度会相应限制外轮目标。内轮目标为零不代表物理锁轮，未使用倒转或双轮反向原地转弯。何时开始转弯、传感器到轮轴的距离、最低转角、离口距离和实际时限仍需实车标定。`route_candidate_samples`、`route_turn_capturing`、`route_turn_rad` 帮助区分未触发与转弯后找线失败；`route_repeat_count` / `route_completed_laps` 显示循环配置和进度。

## 元器件图形与丢线航向保持

普通位置控制只接受单一、宽度不超过 4 路的有效区域。即使底层传感器分类通过连续性选中了多区域中的一段，导航层仍将其视为干扰。无白线、全白、宽线、多区域以及未确认路口都不更新正常位置 PID；窗口内满足骤变条件的 LEFT/RIGHT 优先提交路径动作，其余进入干扰。

第一次异常保存当前编码器航向 `hold_heading_rad`，将基础速度降到不超过 6 cm/s：

```text
correction_cm_s = heading_kp × (hold_heading_rad - heading_rad)
left_target  = hold_base + correction_cm_s
right_target = hold_base - correction_cm_s
```

这样保持进入干扰时的航向，不把干扰图形转换成白线转向误差。位置积分与微分历史保持冻结，速度内环持续调节。连续 3 帧单一窄白线、且尚未达到截止时限，才重建位置/速度 PID 历史并恢复巡线。

从最后稳定白线起 400 ms，或自进入异常起累计偏移 8 cm，任一先到便停车。异常种类切换及孤立有效帧不刷新基准；截止检查优先于本周期恢复或路口确认。旧的“120 ms 保持 + 280 ms SEARCH”已移除。本次不通过扩大丢线时限假定元器件图案一定可穿越。

一维传感器无法区分完全相同的观测：窗口内与路口同形的图案可能被确认，持续窄图形可能被当作白线。编码器不能发现所有轮胎打滑；仅靠双轮里程保持的是估计航向。必须在真实图案、虚线与电量变化下记录并标定。

## 故障与验证

软件停车会在清零目标与 PID 前锁存 `g_diagnostics.stop_snapshot`，包括停车前状态、路径更新前状态/失败原因、当帧原始与滤波灰度/编码器计数、动作转角与阶段时间、最后可靠线年龄、清零前目标与实测轮速。记录在下一次接受 START 时清空；停止后的正常采样与拒绝的 START 不覆盖，复位/断电丢失。用于停车后读取，无需运行中暂停；硬故障/初始化失败或看门狗复位不保证产生有效快照。

`speed_fault` 为 0 无、1 非法间隔、2 非法目标/反馈、3 反向反馈、4 持续低速、5 PID 数值；`speed_fault_wheel` 为 0 公共/无、1 左、2 右。速度控制失败后先在快照中保存细分原因，再由原停车流程清空速度 PID；保护阈值及停车行为保持原约束。里程计异常同样使用 `LINE_STOP_ENCODER`，此时速度子码通常为 0。

针对用户反馈“转后沿出口低速直行后停”，合成输入可在已看到中心线、两轮持续前进但估计转角小于 1.35 rad 时，保持 `ROUTE_EXECUTING` 的出口捕获直到 4500 ms 超时。这仅证明该现象有软件路径，不能证明实车根因；快照的 `route_state_before_update`、`route_failure`、`turn_rad` 与 `observation` 用于下一次区分转角未确认、离口未完成、丢线与编码器故障。

- 上电停止，启动需尺寸配置有效、明确请求、连续有效窄白线。
- 两路编码器初始化/启动返回值逐项检查；右路启动失败会停止已启动左路，随后异常停车。
- 计数跳变超出物理速度上界及量化余量、不可判定半圈增量、非法 dt/数值停车。
- 有非零速度指令时，反向反馈小于 −0.5 cm/s，或目标至少 3 cm/s 而测得速度低于 0.5 cm/s 持续 350 ms，则以编码器/堵转故障停车并锁定，需复位。这不能检测所有单相断线、打滑或错误脉冲，阈值受分辨率影响。
- 任务单次间隔 >15 ms 或计算/回调耗时 >=5 ms 锁定故障停车；保留 IWDG。
- 标定确认门禁不替代硬件电平、供电、STBY 停车、架空轮向和实车验证。

主机入口 `sh test/run_host_tests.sh` 包含传感器/PID/PWM、双环与里程/路口/干扰/完整示例流程，以及电机和编码器 HAL 模拟；均开启 ASan/UBSan。`pio run -e genericSTM32F103C8` 交叉构建所有生产模块。准确执行结果见 [验证记录](validation.md)。

### 2026-10-23 提前减速与转后提速

`JUNCTION_APPROACH_DISTANCE_CM=5.0f` 指表内路口标称位置之前的减速区间，容差仅用于路口检测窗口。剩余距离 `r = step.distance - progress` 在 0…5 cm 时，以 `sqrt(vslow² + (vcruise²-vslow²)*r/5)` 限制基础目标；`vslow=min(vcruise,10)`。候选维持低速，转弯沿用分阶段目标。达到转角及连续中心出口线确认、进入离口后，就按 160 cm/s² 向下一段目标加速（6→50 cm/s 的目标规划约 0.275 s）；循环边界预看首项。离口去重期间仅速度预看下一段，路径索引与里程基准通常在前进至少 3 cm 并连续窄线确认后推进；紧邻下一路口且未越窗时，已确认转弯可用 0.5 cm + 连续 3 帧窄线提前交接。预看时下一段进度使用转弯及离口已累计的出口方向位移，下一段的低速目标或短段减速包络依然生效；不重置 START 包络，异常丢线仍降速并限时停车。当前首段 104±16 cm、50 cm/s 对应 99 cm 开始减速、104 cm 基础目标降至 10 cm/s；窗口内提前确认仍立即低速动作。仅巡线模式不使用该距离包络。
