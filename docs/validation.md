## 已执行：产物静态核对

使用工具链 `readelf`、`nm` 与二进制向量表读取检查：ELF32 ARM、little endian、soft-float ABI；`main`、`SysTick_Handler`、`HardFault_Handler` 和诊断符号已链接。BIN 初始栈 `0x20005000`，复位向量 `0x08002361`，SysTick 向量 `0x0800226d`，均与 ELF 符号一致。

firmware.bin  004eb0962be38c3a73c391ef2ccd5eec558e1b979bf53c45cc42f79ccaaf9475
