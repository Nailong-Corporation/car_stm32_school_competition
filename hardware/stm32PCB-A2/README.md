## 已落实的接口

| 位号 | 板上器件 / 用途 | 引脚定义 |
| --- | --- | --- |
| J1 | 2.54 mm 1×2 公排针，稳压逻辑电源输入 | 1=+5V，2=GND |
| J2 | 2.54 mm 1×2 公排针，电机电源输入 | 1=VM，2=GND |
| J3 | 2.54 mm 1×2 公排针，左电机 | 1=AO1，2=AO2 |
| J4 | 2.54 mm 1×2 公排针，右电机 | 1=BO1，2=BO2 |
| J6、J7 | 两个 2.54 mm 1×20 排母，STM32 开发板插座 | 对应原模块符号 1～20、25～44 脚 |
| J8、J9 | 两个 2.54 mm 1×8 排母，TB6612 模块插座 | 对应原模块符号 1～8、9～16 脚 |
| J10 | 2.54 mm 1×10 排母，灰度接口 | 1=+3V3，2=GND，3～10=S0～S7 |
| SW1 | 常开轻触按键 | 1/2=PB10 的 BTN 网络，3/4=GND；按下连通两组触点 |
| R1 | 10 kΩ，0603 | STBY 到 GND 的外部下拉 |
| C1、C2 | 100 nF / 50 V、10 μF / 25 V | VM 到 GND，后续 PCB 靠近驱动模块布置 |
| C3、C4 | 100 nF / 50 V、10 μF / 25 V | +3V3 到 GND，后续 PCB 靠近驱动模块 VCC 布置 |

电机输出 AO1/AO2、BO1/BO2 是桥式驱动的两线输出，不把任意一端接 GND。J3/J4 已有实际排针封装，PCB 阶段还需放置并完成布线。

逻辑 +5V、驱动 VM、+3V3 是三个独立网络。J1 经 STM32 开发板的 5V 引脚供电，灰度与 TB6612 的逻辑电源接开发板的 3.3V；必须核实开发板稳压器的实际带载能力。J2 的电压按实际电机确定。各模块及两个电源输入共地。外接 J1 的 +5V 与开发板 USB 供电二选一，当前未设计自动电源切换。

## 模块表示与机械约束

用户确认灰度为 3.3 V 供电，针距按普通杜邦连接器的 2.54 mm，两排之间距离为 15.00 mm。

P1 的 U1 / U2 / U3 是静态模块接线示意，原有 20 条导线及其几何路径保留；实际 PCB 器件由 P2 的排母表示。这使导出的 PCB 网表包含真实插座，而非缺少封装的外置模块。原先 J5 对应开发板自带 SWD，现仅保留说明，调试器直接接开发板，不在载板重复安装一个没有物理连接到开发板的 SWD 排针。

- STM32：J6-1 对应 VBAT 所在端，对侧为 J7-20 的 3V3；两排的编号方向相反。
- TB6612：J8-1 的 VM 对侧为 J9-1 的 PWMA；两排的编号方向相同。
- STM32 插座上当前不用的 18 个针脚已明确标为不连接；PA9/PA10 等预留脚可在后续需求明确后接出。
- 15.00 mm 是用户指定的排间中心距，已写入图面和本说明；不能用常见的 15.24 mm 代替。
- 本次未修改 PCB 布局，单排排母封装本身不锁定两排之间的位置；PCB 阶段须落实中心距、相对端点和朝向。
- 必须再用实物核对公母配合、排数/针数、从插入面观察的针序、模块外形、USB 插头空间与器件避让；当前未证明可直接插装或可生产。

采用的 20 针与 8 针排母料号分别为 C50984、C27438，已核对其 2.54 mm 单排接口资料，并使器件属性与关联封装匹配。参考 [立创 20 针排母资料](https://www.lcsc.com/zh-CN/product-detail/C50984.html) 与 [立创 8 针排母资料](https://www.lcsc.com/zh-CN/product-detail/C27438.html)。
